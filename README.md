# Práctica OPTATIVA GIT

Repositorio del proyecto web desarrollado para la práctica de Git y GitHub.

## Contenido

- `index.html`: estructura principal de la página.
- `app.js`: lógica básica del proyecto.
- `style.css`: hoja de estilos.
- `login/`: archivos de la rama de inicio de sesión.
- `autenticacion/`: archivos de autenticación.
